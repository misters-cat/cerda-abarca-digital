# Cerda-Abarca Digital

Landing page institucional de Cerda-Abarca Digital, marca tecnológica detrás de MiAuto Wallet.

## Publicación

Sitio HTML estático: `index.html` en la raíz.

En Netlify: importar el repositorio de GitHub, seleccionar la rama `main`, dejar el comando de compilación vacío y publicar desde `.` (raíz del repositorio).

## Actualizaciones

Modificar `index.html`, confirmar los cambios en `main` y Netlify publicará automáticamente.
